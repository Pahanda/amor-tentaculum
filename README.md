# Amor Tentaculum
A RimWorld Tentacle Mod

This mod was originally created by MrCastle69 (who is MIA) and was maintained by IcePokeDude. It is being taken over with permission from IcePokeDude, as it needs some love - just like these tentacles do.

If you'd like to help, please feel free to make use of the Github Issues tracker and/or stop by the RJW Discord thread for the mod.

# Caveat Modder
At the moment, this mod is EXTREMELY a Work In Progress. The original mod was unfinished and had quite a few bugs. Most of the bugs have been squashed and the core concepts are being implemented, but there's still more work to do.

Because of this, you may not want to use this in an active game (or if you do, be mindful of updating), as things are still changing and your save game might break.

For the moment, we do not promise any sort of forwards-compatibility; we will lock down def names once we hit an Alpha stage, which should avoid serious breakage, but we're not there yet.

We also do not recommend upgrading from the old 1.6 version of the mod to this version. Enough has changed that this will **absolutely** break your save.

Finally, this mod is being developed exclusively for the 1.7 RimWorld client (which is currently on an "unstable beta" build). While it may work on the 1.6 client, we do not promise this, nor can we support any attempts to get it working.

# Mod Dependencies

Hard Requirements (this mod will not work without them):
* [Harmony](https://steamcommunity.com/sharedfiles/filedetails/?id=2009463077)
* [RJW](https://gitgud.io/Ed86/rjw)
* [RJW Genes](https://github.com/vegapnk/RJW-Genes)
* [Biotech (Official DLC)](https://store.steampowered.com/app/1826140/RimWorld_Biotech/)
* [EBSG Framework](https://steamcommunity.com/sharedfiles/filedetails/?id=3112549163)
* [Vanilla Expanded Framework](https://steamcommunity.com/sharedfiles/filedetails/?id=2023507013)

Soft Requirements (this mod provides additional features if you have these installed):
* [RJW Onahole Extension](https://gitgud.io/splicing3089/rimjobworld-onahole-extension) (adds tentacle-specific Onaholes and traps - **you know you want this**)
* [Royalty (Official DLC)](https://store.steampowered.com/app/1149640/RimWorld_Royalty/) (some pawns get buffs to psychic sensitivity)
* [Ideology (Official DLC)](https://store.steampowered.com/app/1392840/RimWorld_Ideology/) (provides memes and other Ideology components for your tentacle colony)
* [Odyssey (Official DLC)](https://store.steampowered.com/app/3022790/RimWorld_Odyssey/) (provides vacuum resistance to converted pawns and has some additional structures for gravships)

Recommended Mods (never required, but provide useful things to suppliment a tentacle colony):
* [Alpha Memes](https://steamcommunity.com/sharedfiles/filedetails/?id=2661356814) (provides a Flesh Cult structure style for your Ideology that fits this mod well; note that the Anomaly DLC is required for this style)
